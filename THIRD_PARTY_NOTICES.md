## OpenClaw

The MCAI model-cloud system prompt architecture is inspired by the layered prompt design documented and implemented by OpenClaw.

- Project: https://github.com/openclaw/openclaw
- Reference commit: `90a22b4f50226b13735e77dde81a92340ae724cf`
- License: MIT
- Copyright: Copyright (c) 2026 OpenClaw Foundation

MCAI uses an independently adapted Minecraft operations prompt. It retains OpenClaw-inspired concepts such as stable and dynamic prompt sections, exact tool contracts, execution follow-through, evidence-based completion, and safety priority, while replacing OpenClaw-specific tools, channels, memory, workspace, and runtime instructions with MCAI Cloud and Sidecar contracts.
